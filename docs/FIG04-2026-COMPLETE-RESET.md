# FIG 04 / Complete creative reset — 19 October 2026

## Why the previous six are being replaced

The second rebuild is correct but still reads as one design six times: the same 40–54px navy headline, monospaced eyebrow, mint disclosure, bordered proof cells, and a decorative object that often sits *beside* the argument. Five desktop sections exceed 950px, and phone pages run about 1,500–1,800px. The responsive versions commonly become a long stack of nearly identical text cards. The work is tidy, but too many routes lead back to the same visual grammar. The user asked for complete designs, not another adjustment to the six carriers.

The six sample URLs/IDs remain stable for bookmarks. Their HTML, concepts, names, metadata, thumbnails, and gallery presentation are being rewritten. We will not change FIG 01–03 or construct entire homepages.

## Current design research inspected for this reset

These are design references, **not evidence for Nestlancer claims**. No third-party composition, art, code, logo, UI screenshot, testimonial, or metric is copied.

- [Codrops / Heron AI, 12 Oct 2026](https://tympanus.net/codrops/2026/10/12/heron-ai/): the designers abandoned a safe generic SaaS direction and built the visual vocabulary from the product’s actual working materials. Translation: use Nestlancer’s supplied nouns—scope, reply, pay, gate, search—as the shape and behaviour of each direction. A decorative circle plus six cells is not enough.

Translation: give every study a different physical rhythm, not a different icon set inside the same grid.
- [Wix / 2026 web design trends](https://www.wix.com/blog/web-design-trends): exaggerated hierarchy, tactile materiality, and museum-like editing can replace generic minimalist emptiness. Translation: test one proof-led typographic wall and one material/sculptural approach, while keeping the studio’s palette and legibility.
- [Figma / Top Web Design Trends for 2026](https://www.figma.com/resource-library/web-design-trends/): bold type and purposeful motion are valuable when they guide attention, not when they turn every mid-page heading into a hero.
- [Web Design Awards / SaaS rubric, updated Oct 2026](https://www.webdesignawards.io/categories/saas): strategy, distinct branding, storytelling, accessibility, performance, and responsive behaviour are evaluated together. Translation: a gallery of six attractive screenshots is insufficient if one fails on a phone or hides proof text behind an interaction.
- [Codrops / Isle Thorne, 7 Oct 2026](https://tympanus.net/codrops/2026/10/07/isle-thorne-collective-astro-template/): a site-wide grid aligns details, but real design comes from what each element does within it; native controls can carry interaction without a large framework.

## Rendered critique and verification

The gallery now uses six small **screenshots of the actual light-mode implementations**, not speculative CSS thumbnails. The full-resolution artwork belongs only to W02; W06's plates and W04's paths are hand-authored CSS/SVG. All six were visually reviewed at **1440 and 390px in light and dark modes** (temporary full-page captures are under the ignored `tmp/fig04-reset/` directory).

- **W01** is intentionally the most austere: the payout amount and first qualification form the hero treatment, while five open statements hold the rhythm. Dark mode remains typographic rather than inventing an object.
- **W02** is the only photographic-looking, generated abstract artwork. Its light image remains light inside the dark section, preserving the material contrast. On phones the image follows the heading and precedes the index; the first qualified proof appears in the initial viewport.
- **W03** is the only working search. The input placeholder was shortened after phone rendering so it no longer collides with its keyboard hint. Search concerns this local section only; nonmatches remain readable.
- **W04** joins six open proof lines with an orthogonal rectangle, not a circular lens or timeline. The manifold becomes a brief decorative header on phones, where the full 01–06 reading path follows.
- **W05** is the sole six-card mosaic. Unequal spans and claim-specific marks separate it from a generic feature grid; dark mode keeps readable mint type against its deeper tiles.
- **W06** is intentionally tactile and the longest desktop study (about 1410px): the three-layer conceptual object leads into six offset proof slats. The tradeoff is length, not hidden evidence; on phones all six slats remain open and the amount and qualifier occupy the first slat.
